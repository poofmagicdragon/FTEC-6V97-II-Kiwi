How do we generate an access token?

Workflow:
1. Access the login page, enter a username + Password (code challenge)
2. Page will redirect to the url that we provided at setup + attach a special code in the url query parameter
3. Take this code and make another API call to Cognito and exchange the code with the token (code_verifier)

Step 2 : how do we exchange the code for a token
Make an API call to Cognito to exchange the auth code (giving also the code verifier) with an access token

When attaching a token to the HTTP request, the standard practice is that we attach a header called authorization with a value Bearer <token>
header: Authorization = Bearer <token_string>
